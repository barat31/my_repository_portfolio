PORTOFOLIO BASIC — PANDUAN SINGKAT

1. Ekstrak file ZIP.
2. Buka folder portfolio_basic.
3. Klik dua kali index.html untuk melihat website di browser.
4. Untuk mengedit, buka folder menggunakan Visual Studio Code.

FILE:
- index.html  : isi konten dan struktur halaman.
- style.css   : warna, ukuran, layout, dan responsive design.
- script.js   : menu mobile, teks animasi, dan navigasi aktif.

BAGIAN YANG PERLU DIGANTI:
- Ganti "Nama Anda" dan inisial "NA" dengan identitas Anda.
- Ganti emailanda@example.com dengan email aktif.
- Ganti tautan # pada LinkedIn, GitHub, Instagram, sertifikat, dan detail projek.
- Ganti pengalaman, nama universitas, tahun, serta sertifikat dengan data asli.
- Untuk foto profil: ganti elemen .profile-placeholder di index.html dengan
  <img src="assets/foto-profil.jpg" alt="Foto Nama Anda"> lalu sesuaikan CSS.

Catatan:
Website ini menggunakan HTML, CSS, dan JavaScript biasa (tanpa database dan tanpa hosting).
Untuk dipublikasikan online, folder ini dapat diunggah ke layanan hosting statis seperti
GitHub Pages atau Netlify. Google Fonts membutuhkan koneksi internet; font cadangan tetap tersedia.
